Methods

Reads aligning to the reference (NC_000932.1.fasta, 154,478 bp) were extracted with minimap2 2.31-r1302 (-x sr); read pairs were kept whole when either mate matched. Reads shorter than 50 bp or failing fastp's quality filters were removed and adapters trimmed with fastp 1.1.0; the reads (pairs kept whole) were then subsampled evenly to at most 100x of the reference length. Each sample was assembled by reference-guided consensus: reads were aligned to the reference with minimap2 and the consensus called with samtools consensus 1.24 (-X hiseq, minimum depth 3, minimum call quality 20; positions with less support, or where the reads disagree, are N). Each genome was aligned to the reference with minimap2 2.31-r1302 (-x asm20) and read position by position in the reference's coordinates (insertions left out; a base was taken as N where two alignments gave different bases, or with at least 3 N within 50 positions); SNPs were the positions covered by all genomes at which the genomes differ. Pairwise SNP distances count the positions where both genomes have a nucleotide and they differ. The SNPs of each genome relative to the reference were written to a VCF file from every position where the genomes differ. A tree was built on the SNP alignment with FastTree 2.2.0 (GTR, SH-like supports from 100 resamples) and rooted at its midpoint. Genes were read from the annotation NC_000932.1.gb; the effect of each SNP on the coding sequences (codon and amino-acid change) was derived by RASHER with translation table 11. The LSC/IRb/SSC/IRa regions were derived from the inverted repeat detected in the reference sequence (two copies of 26,264 bp, 100% identical). The inverted repeat is found by matching the k-mers of the sequence with those of its reverse complement, chaining the matches and extending them base by base (each copy at least 5 kb, at least 99% identical). The analysis was run with RASHER 0.1.0 (https://github.com/duceppemo/RASHER).
